# 212°F Franchise Egypt

Code-first redesign of the official 212°F Franchise Egypt website: a premium, responsive B2B experience built around the brand's “extra degree” idea.

## Stack

- Next.js App Router + TypeScript
- Tailwind CSS
- GSAP + `@gsap/react`
- Lucide icons

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Design direction

Official navy `#253C5F`, red `#D0252A`, charcoal `#282828`, and Helvetica-led typography. Motion is purposeful, accessible, and disabled when reduced motion is requested.
